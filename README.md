# arvisclinic.ru — снимок для дизайн-аудита

[Открыть полный снимок в ветке audit-snapshot](https://github.com/viktorivanov28256-create/arvisviktorr/tree/audit-snapshot)

Снимок общедоступен и читается без входа в GitHub, в том числе Клодом.

- 367 уникальных конечных страниц: все 323 адреса sitemap.xml и дополнительные внутренние ссылки, включая /en/, /search/ и 404.
- 734 полностраничных JPEG: 390 и 1440 px, качество 80. Cookie-уведомление не закрывалось.
- 32 пропущенных файла перечислены в meta/skipped.txt.
- 2 665 файлов; все опубликованные Git blob SHA сверены с локальным манифестом.

- [URL, статусы, редиректы, размеры и заголовки страниц](https://github.com/viktorivanov28256-create/arvisviktorr/blob/audit-snapshot/meta/urls.csv)
- [Карта скриншотов](https://github.com/viktorivanov28256-create/arvisviktorr/blob/audit-snapshot/meta/shots.json)

- [Манифест размеров и контрольных сумм](https://github.com/viktorivanov28256-create/arvisviktorr/blob/audit-snapshot/file-manifest.json)

HTML, CSS, JS и ссылки сохранены без переписывания. Значения служебных cookie и авторизации исключены из заголовков. Запросы выполнялись без авторизации и cookie, с настольным Chrome User-Agent и общим ограничением менее 2 запросов в секунду. Скриншоты отрисованы из сохранённых ответов в изолированном Playwright без дополнительных сетевых запросов.

Приватные файлы сервера, настройки доступа, дампы, резервные копии, PHP-ядро Битрикса и серверные логи не включены. source/README.md описывает доступность исходников текущей версии.
