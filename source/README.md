# Исходники

Подтверждённые Git-исходники текущего публичного сайта в этот снимок не добавлены. Корень проекта не является Git-checkout; найденный локальный макет не подтверждён как версия действующего сайта на Битриксе.

Основной материал аудита — страницы и публичные ресурсы, полученные по HTTP. Архивные пакеты внедрения и приватные резервные копии не использовались как исходники. Ядро PHP Битрикса, серверные настройки, ключи, токены, SQL, журналы и данные пациентов не включались в `source/`.
